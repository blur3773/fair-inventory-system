# Ответы на контрольные вопросы ПР1

## По материалам «Основы Python»

1. **Какие основные типы данных используются в Python?** `int`, `float`, `str`, `bool`; также используются коллекции: `list`, `tuple`, `dict`, `set`.
2. **Чем отличаются `int`, `float`, `str` и `bool`?** `int` хранит целые числа, `float` — вещественные, `str` — текст, `bool` — логические значения `True` и `False`.
3. **Для чего используется преобразование типов?** Чтобы получить значение нужного типа, например преобразовать введённую строку в число: `int("50")`.
4. **Какие операции можно выполнять со строками?** Соединять, повторять, получать символы и срезы, проверять вхождение, длину и применять строковые методы.
5. **Какие операторы сравнения используются в Python?** `==`, `!=`, `<`, `>`, `<=`, `>=`.
6. **Для чего используется конструкция `if`?** Для выполнения кода только при истинности заданного условия.
7. **В чём различие между `if`, `elif` и `else`?** `if` проверяет первое условие, `elif` — дополнительные условия, `else` выполняется, если предыдущие условия ложны.
8. **Как записываются составные условия?** Несколько выражений объединяются операторами `and`, `or` и `not`, при необходимости используются скобки.
9. **Для чего используются `and`, `or` и `not`?** `and` требует истинности всех условий, `or` — хотя бы одного, `not` меняет логическое значение на противоположное.
10. **Что такое модуль Python?** Файл с кодом Python, содержащий функции, классы и переменные для повторного использования.
11. **Для чего используется `import`?** Для подключения модулей и применения их объектов в программе.
12. **Чем импорт модуля отличается от импорта отдельного объекта?** `import module` подключает модуль и требует обращения через его имя, а `from module import object` добавляет выбранный объект напрямую.

## По рабочему окружению

13. **Для чего используется виртуальное окружение Python?** Оно изолирует версию интерпретатора и зависимости конкретного проекта от остальных проектов и системы.
14. **Что такое IDE?** Среда разработки, объединяющая редактор кода, запуск, отладчик, навигацию и другие инструменты программиста.
15. **Для чего используется Git?** Для сохранения истории изменений, возврата к версиям и совместной работы над кодом.
16. **Что такое репозиторий?** Каталог проекта, в котором Git хранит файлы и историю их изменений.
17. **Что такое commit?** Зафиксированный снимок изменений с автором, датой и сообщением.
18. **Для чего нужен `.gitignore`?** Чтобы исключить из репозитория служебные и локальные файлы, например `.venv` и `__pycache__`.
19. **Для чего нужен `README.md`?** Чтобы описать назначение проекта, его функции, запуск и дальнейший план разработки.
20. **Что такое отладка?** Процесс поиска причин неправильной работы программы путём контролируемого выполнения и анализа состояния.
21. **Что такое breakpoint?** Точка останова, в которой отладчик приостанавливает программу для проверки переменных и потока выполнения.
22. **Для чего используется пошаговое выполнение программы?** Чтобы выполнять код по строкам и видеть, как меняются значения и где появляется ошибка.

## По индивидуальному проекту

23. **Какую задачу решает выбранное приложение?** Оно учитывает товар продавца на стенде ярмарки, рассчитывает остаток и выручку и показывает состояние запаса.
24. **Кто является предполагаемым пользователем?** Продавцы и организаторы ярмарок.
25. **Какие основные сущности выделены в предметной области?** Продавец, товар, стенд и количество.
26. **Какие функции планируется реализовать?** Учёт товарных позиций, привязку продавцов и товаров к стендам, регистрацию продаж, расчёт остатков и выручки, отчёты и управление доступом.
27. **Какой сценарий реализован на текущем этапе?** Обработка одной товарной позиции: проверка значений, расчёт остатка и выручки, определение состояния запаса и вывод сводки.
28. **Какие конструкции Python использованы в программе?** Переменные, `int`, `float`, `str`, `bool`, преобразование типов, арифметика, сравнения, `if`, функции, аннотации типов, форматированные строки и импорт `date`.
29. **Какие части будут добавлены после изучения ООП и Django?** Классы предметной области, база данных, модели Django, веб-интерфейс, авторизация, права доступа, REST API, тесты, контейнеризация и CI/CD.
30. **Почему предметная область подходит для веб-приложения?** Нескольким продавцам и организаторам нужен общий доступ к актуальным сведениям о товарах, стендах, остатках и продажах с разных устройств.

# Система учёта товаров на ярмарке

Консольное приложение для учёта товаров продавцов на стендах ярмарки, продаж, остатков и выручки.

## Назначение и предметная область

Приложение помогает организаторам и продавцам ярмарки вести учёт нескольких товарных позиций. Для каждого товара хранятся продавец, стенд, исходное количество и цена. Продажи уменьшают остаток и учитываются в общей выручке.

## Основные сущности

- **Товар** — позиция продавца с исходным количеством и ценой.
- **Продавец** — участник ярмарки, реализующий товары.
- **Стенд** — место размещения товара на ярмарке.
- **Продажа** — запись о проданном количестве товара, дате и выручке.

## Возможности ПР2

- просмотр всех товаров, их остатков и состояний запаса;
- поиск товара по части названия;
- проверка наличия товара в нужном количестве;
- добавление товарной позиции;
- регистрация и отмена продажи;
- сортировка и отбор товаров по остаткам;
- просмотр журнала продаж и статистики по выручке;
- сохранение и загрузка данных в JSON-файлах;
- безопасная обработка некорректного ввода и ошибок файлов.

Начальный сценарий ПР1 сохранён в данных: для мёда с исходным количеством 50 единиц зарегистрирована продажа 18 единиц, поэтому остаток составляет 32 единицы, а выручка — 8100 руб.

## Структура проекта

- `main.py` — консольное меню и вывод данных;
- `inventory.py` — функции работы с товарами, продажами, остатками и статистикой;
- `storage.py` — загрузка и сохранение JSON-данных;
- `utils.py` — безопасный ввод чисел и дат;
- `data/products.json` — список товаров;
- `data/sales.json` — журнал продаж;
- `tests/test_inventory.py` — автоматические тесты;
- `requirements.txt` — инструменты разработки.

## Формат хранения данных

Данные хранятся в JSON. Каждый товар содержит `id`, название, продавца, стенд, исходное количество и цену. Каждая продажа содержит `id`, идентификатор товара, количество, дату и выручку.

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

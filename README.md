# Система учёта товаров на ярмарке

## Назначение

Приложение помогает учитывать товары, размещённые продавцами на стендах ярмарки, рассчитывать остаток и выручку, а также определять состояние запаса.

## Целевая аудитория

Организаторы ярмарок и продавцы, которым нужен простой учёт количества товаров на конкретном стенде.

## Предметная область

На ярмарке продавцы размещают товары на закреплённых стендах. Для каждой позиции необходимо знать исходное количество, число проданных единиц, остаток, цену и полученную выручку.

## Основные сущности

- **Продавец** - участник ярмарки, реализующий товары.
- **Товар** - позиция, выставленная на продажу.
- **Стенд** - место размещения продавца и товара.
- **Количество** - исходный запас, проданное число единиц и текущий остаток.

## Основные функции

- расчёт оставшегося количества товара;
- определение состояния запаса;
- расчёт выручки от продажи;
- формирование сводки по товару на стенде.

## Реализованный сценарий ПР1

Программа обрабатывает одну товарную позицию: проверяет исходные значения, рассчитывает остаток и выручку, определяет состояние запаса и выводит сводку по продавцу, товару и стенду.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python main.py
```
